## 样式与设计系统

- 新建页面不在主内容区最上方单独添加页面主标题、解释性副标题或说明段落，也不添加与标题并列的“返回概览”入口。内容区直接从必要的工具栏、筛选控件或业务面板开始，不预留标题行的空白；面板、表格和弹窗内部的功能标题按需保留。
- 左侧品牌名称下方不放说明文案。功能所需的提示保留在对应控件或内容区域。
- 页面、面板和页签不添加装饰性英文眉题或与中文标题重复的英文说明，例如 `CATALOG`、`TABLE RESOURCE`、`INSPECTOR`、`SCHEMA`、`SAMPLE DATA`、`PROFILE AGENT`。保留必要的中文功能标题；数据库名、表名、字段名、类型、FQN、Schema 等业务标识和技术术语不因含英文而删除。
- 清理此类说明时，检查受影响页面各页签中的同类文案，直接移除对应渲染节点，不保留空占位或额外标题留白；修改共享组件前确认页面实际引用关系及影响范围，保持无关页面和已确认区域不变。
- 项目默认使用暗色主题。新增页面和组件应沿用现有暗色背景、面板、文字及交互状态 Token；
- 所有可见文字的字号不得小于 `14px`，包括辅助说明、表格内容、标签和按钮文字。空间紧张时先调整布局或留白，不要缩小字号。
- 页面主内容区的目录、列表、详情等并排边框面板，默认填满扣除标题、工具栏和页面留白后的窗口剩余高度，同一行面板的上下边界对齐。面板不得因内容较少、筛选结果减少或空状态而收缩；不要仅用固定像素的最小高度代替填满布局。此规则适用于主内容面板，普通指标卡片、按钮和弹窗按各自用途确定高度。
- 填满高度的面板应由页面容器及 Flex/Grid 布局分配可用空间，内容超出时在对应面板内部滚动，不撑长整页。较窄电脑窗口需要换行时，保留合理的面板高度和页面滚动；检查空状态、筛选后少量内容及大量内容时，边框高度、文字和操作区域均正常。
- 本项目界面仅面向电脑端，不设计或验证手机、平板等移动端布局。修改样式或交互后，检查常用电脑屏幕和浏览器窗口尺寸下的布局、文字可读性、状态区分、溢出、遮挡及滚动区域；保持本次任务未涉及的已确认视觉区域不变。

## 数据可视化大屏

- 设计数据可视化大屏时，先阅读并参考同目录的[《数据可视化大屏设计笔记》](./数据可视化大屏设计笔记.md)，结合实际屏幕和观看距离确定信息层级、字号、图表与告警展示。

## 表格分页与内部滚动

- 填满剩余高度的列表面板中，分页栏固定在面板底部右侧并始终可见，不随当前页行数、筛选结果或空状态上下移动；表格内容在独立区域内滚动，分页不得放入该滚动区域。
- 使用 Flex/Grid 分配表格剩余空间，标题和分页不参与压缩。检查从面板到表格的完整高度链；Ant Design Table 的 `.ant-table-wrapper`、`.ant-spin-nested-loading`、`.ant-spin-container` 等中间容器需正确传递剩余高度并允许收缩（如 `flex: 1`、`min-height: 0`），只在表格内容区域开启滚动。样式限定在受影响页面，避免修改全局表格规则。
- 不假定 Table 在零条数据时仍会渲染分页。要求始终显示分页的页面需检查当前组件版本的实际行为；必要时为空状态补充禁用分页，保持位置、留白和总数展示一致，避免与非空状态的分页重复显示。
- 分页布局验收覆盖多条数据、单条数据、空数据及表格滚动前后，并在常用桌面窗口尺寸下确认分页位置稳定、完整可见、内容仍可访问。组件级模拟验证与真实业务流程验收分别说明，不将模拟结果表述为完整页面验收。
