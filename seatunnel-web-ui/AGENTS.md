## 样式与设计系统

- 新建页面不在主内容区最上方单独添加页面主标题、解释性副标题或说明段落，也不添加与标题并列的“返回概览”入口。内容区直接从必要的工具栏、筛选控件或业务面板开始，不预留标题行的空白；面板、表格和弹窗内部的功能标题按需保留。
- 左侧品牌名称下方不放说明文案。功能所需的提示保留在对应控件或内容区域。
- 项目默认使用暗色主题。新增页面和组件应沿用现有暗色背景、面板、文字及交互状态 Token；
- 所有可见文字的字号不得小于 `14px`，包括辅助说明、表格内容、标签和按钮文字。空间紧张时先调整布局或留白，不要缩小字号。
- 页面主内容区的目录、列表、详情等并排边框面板，默认填满扣除标题、工具栏和页面留白后的窗口剩余高度，同一行面板的上下边界对齐。面板不得因内容较少、筛选结果减少或空状态而收缩；不要仅用固定像素的最小高度代替填满布局。此规则适用于主内容面板，普通指标卡片、按钮和弹窗按各自用途确定高度。
- 填满高度的面板应由页面容器及 Flex/Grid 布局分配可用空间，内容超出时在对应面板内部滚动，不撑长整页。较窄电脑窗口需要换行时，保留合理的面板高度和页面滚动；检查空状态、筛选后少量内容及大量内容时，边框高度、文字和操作区域均正常。
- 本项目界面仅面向电脑端，不设计或验证手机、平板等移动端布局。修改样式或交互后，检查常用电脑屏幕和浏览器窗口尺寸下的布局、文字可读性、状态区分、溢出、遮挡及滚动区域；保持本次任务未涉及的已确认视觉区域不变。
