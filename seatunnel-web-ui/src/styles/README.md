# 公共组件样式

当前采用用户提供的冷色海军蓝视觉规范，保持 React / Ant Design 5 与既有桌面业务布局。

- `theme-tokens.ts`：构建配置与运行时共用的暗/亮实际颜色和几何 Token。参与 Ant Design 颜色派生的 Token 使用实际色值。
- `../design-system.less`：业务 CSS 使用的 `--st-*` 语义变量与存量样式兼容层。暗色默认，浅色作为同谱对照基准；不新增主题切换入口。
- `antd-theme.ts`：通过官方组件 Token 映射表格、按钮、表单、菜单、弹层等公共样式。直接绘制的属性可引用 CSS 变量。
- `antd-components.less`：处理存量强覆盖下的校验、禁用、选中优先级，以及弹窗分区等结构样式；在设计系统之后加载。

暗色页面 `#000E24`、面板 `#000F23`、浮层 `#001630`；实心主按钮 `#126681`，文字链接和焦点强调 `#00C4E5`，常规边框 `#2187A8`。表格表头和弹窗/确认框标题栏共用 `#0E5C78`。主按钮悬停 `#197F9E`，按下 `#093D7E`。选中行优先于悬停和斑马纹，固定列使用相同不透明背景。

字体为 Microsoft YaHei / Helvetica / Arial；正文和辅助文字保持项目要求的最小 14px。控件默认 30px，按钮 32px；圆角 3/6/10px，滚动条 6px。面板的撑满、内部滚动和已确认业务布局保持现有规则。

修改后按影响范围验证官方 Token 类型、构建，以及按钮状态、表单 focus/error/disabled、表格固定列和选中行、弹窗/确认框、空状态及常用电脑窗口尺寸。隔离组件页验证不等于完整业务流程验收。
