# MOD-007 数据安全与 SSO 集成

## 1. 目标

将 SeaTunnel-Web 的人员登录和权限统一接入既有 SSO，并明确 Engine、TDuck、
OpenMetadata、边缘代理与数据源之间的服务/设备认证、链路加密、密钥和审计边界。

人员身份与权限以 SSO 为唯一权威源。本模块不建设用户中心、角色中心或权限配置中心。

## 2. 指标与投标模块映射

- 指标：F-07.01～F-07.02、F-14.03。
- 投标模块：传输链路加密、采集端身份鉴权、边缘安全轻量防护。

## 3. 当前能力和证据

- SeaTunnel-Web 具备基础本地登录、用户会话和权限相关代码，但这些代码不再作为正式身份主干。
- 企业治理规范要求凭据脱敏和集中密钥解析。
- SSO 已确定为人员用户、组织、角色和权限的统一权威源。
- SSO 协议、客户端参数、主体标识、授权声明、退出和失效接口尚待冻结。
- TDuck/OpenMetadata 的 SSO 衔接方式，以及边缘设备的国密和证书体系尚未确定。

## 4. 实施边界

### Reuse

- 复用现有会话承载、后端拦截器、TLS/数据库安全协议和日志框架。
- 如业务外键和历史审计必须保留本地用户记录，只将其作为 SSO 主体映射/显示缓存。

### Modify

- 将现有账号密码登录改造成 SSO 登录跳转、回调、会话校验和统一退出。
- 将现有本地用户管理能力停用或改造成只读 SSO 主体映射，不允许人工维护用户、角色和权限。
- 后端按 SSO 权限声明或统一授权接口，对数据源、任务、表单和元数据资源执行访问控制。
- 为外部系统增加独立的服务账号、最小权限、密钥引用和调用审计。

### Add

- SSO 协议适配器、登录回调、令牌/会话失效、主体映射和权限声明转换。
- 服务到服务认证、证书生命周期和密钥轮换。
- 安全审计事件、敏感字段脱敏和权限回归。

### Integrate

- 既有 SSO 系统。
- 经批准的密码产品、国密网关、证书/密钥管理系统。
- TDuck、OpenMetadata 的 SSO/OIDC/SAML 或反向代理认证能力，具体以 PoC 为准。

### Limited or Mock

- 无。安全核心指标不能用前端 Mock 代替。

### Out of scope

- 不自研密码算法。
- 不开发本地用户、组织、角色和人员权限增删改查。
- 不保留与 SSO 并列的本地账号密码认证。
- 不允许通过本地页面修改来自 SSO 的主体和权限。
- 不在代码、配置或规划产物中保存真实密钥。
- 不把前端隐藏按钮当成权限控制。

## 5. 主要流程与接口边界

```text
人员访问：
用户访问 SeaTunnel-Web
→ 跳转 SSO 登录
→ SSO 回调并建立应用会话
→ 后端校验 SSO 登录态和授权结果
→ 使用 SSO 主体标识记录业务操作
→ 统一退出/会话失效

后台与设备访问：
服务/设备认证
→ 获取服务凭据、设备证书或密钥引用
→ 加密调用外部系统/Engine/数据源
→ 审计和异常告警
```

## 6. 依赖和实施顺序

- 属于 M0，先于所有外部系统和边缘集成。
- 先冻结 SSO 协议、Client ID、回调/退出地址、主体唯一标识、组织/角色/权限字段和失效机制。
- 先完成 SeaTunnel-Web 登录、现有用户关联和 API 鉴权 PoC，再接 TDuck/OpenMetadata 单点访问。
- 国密与 GJB 5612 口径需安全/保密评审批准。

## 7. 验收场景

- 用户只通过 SSO 登录；本地账号密码不能建立正式会话。
- SSO 用户首次或再次登录后，业务记录使用稳定的 SSO 主体标识，组织/角色变更不产生重复人员。
- SSO 会话失效或用户停用后，SeaTunnel-Web 会话按约定时限失效。
- 未授权用户、服务和设备均被后端拒绝。
- 合法主体只能访问 SSO 授权的数据源、表单和任务，前端越权请求同样被后端拒绝。
- SeaTunnel-Web 不提供用户、角色和人员权限维护入口。
- Web、Engine、TDuck、OpenMetadata 调用均使用批准的加密链路。
- 密钥轮换后业务可恢复，日志/API/HOCON 不出现明文秘密。
- 审计可关联主体、资源、动作、结果和 traceId。

## 8. 风险与未验证项

- SSO 产品接入协议、环境、主体字段、权限声明和退出/失效时限尚未冻结。
- 现有本地用户主键与 SSO 主体标识的历史数据迁移/关联规则尚未确定。
- TDuck、OpenMetadata 是否可直接接入同一 SSO，以及社区版限制尚待 PoC。
- 设备证书和服务账号模型未冻结；人员 SSO 不能替代二者。
- 国密算法/产品、硬件密码设备和验收工具尚未确定。
- 外部社区产品的细粒度权限能力可能不足，需要平台侧网关补偿。
