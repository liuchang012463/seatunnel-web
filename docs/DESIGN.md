# 数据中台引接分系统 · Redesign 方向与 Design System

> 分支：`redesign`（2026-09-12）。状态：**提案，待评审**——未经明确批准不落任何正式页面/共享组件。
> 上游文档：审计见 [`ui-ux-audit.md`](./ui-ux-audit.md)；既有视觉基线 [`../DESGIN.md`](../DESGIN.md)（探查域）继续有效，本文将其升级为全站系统。
> 参考原型：`docs/redesign/prototype/`（静态隔离 HTML，仅评审用）。

## 1. 设计方向（一句话）

**「值班仪表台」，不是「游戏 HUD」**：把系统做成一间安静的暗色机房控制台——表面靠深浅分层与发丝线分区，信息靠排版与等宽数字说话，唯一的亮色是青色强调与状态语义色；把"胆量"全部花在一处：**状态优先的高密度数据表**（本产品的核心画面），其余一切克制。

三条硬边界（来自任务要求 + frontend-design 反模式校准）：

- 保留军工暗蓝科技风（`#001922` 系深青蓝底 + 青色强调），但**不做**霓虹辉光、赛博朋克、大面积渐变、边框套边框的 Card 套 Card、通用 AI 仪表盘版式。
- 高信息密度优先：中台用户"一屏看更多行"，密度档位是一等公民。
- 状态永远"色 + 文"双通道，禁止只靠颜色传达。

### 自检记录（对照 frontend-design 通用 AI 风格清单）

| 风险点 | 决策 |
| --- | --- |
| 全大写眉题滥用（generic tell） | 仅保留三栏工作台的**区域标识**（CATALOG / INSPECTOR 这类承担结构信息的），普通页头不再加英文眉题 |
| 单词变色/斜体的标题 | 不用；标题靠字号与 500 字重建层级 |
| 紫色/酸绿单强调（AI 默认） | 强调色收敛为青色一族；图表主题注册为青-绿色阶，杜绝 ECharts 默认紫 |
| 每卡同阴影圆角的 SaaS 卡片堆 | 面板用表面色差 + 发丝线分区，表单/表格容器去边框；圆角全局 2-4px 两档 |
| 等宽字体当装饰 | 等宽只用于领域语汇：IP、JDBC URL、任务 ID、指标数字（tabular-nums） |
| 无意义入场动画 | 仅保留 hover/focus/展开三类 120-160ms 动效，尊重 prefers-reduced-motion |

## 2. 设计原则（评审用，实施时逐条对照）

1. **状态先行**：列表第一层信息是"健康吗"，第二层才是配置是什么。失败可从行内直达原因。
2. **结构靠留白与发丝线，不靠盒子**：禁止 bordered panel 套 bordered table；同一屏最多一层边框。
3. **一屏一主操作**：每页一个主按钮；行内动作 ≤2 个可见 +「更多」；危险动作进「更多」并二次确认。
4. **数字即界面**：指标右对齐、等宽、带单位；时间统一 `YYYY-MM-DD HH:mm`；代码类值（ID/URL/IP）用等宽不截断语义。
5. **说人话**：菜单名 = 页面标题 = 面包屑同词；不暴露内部码（UNIT_xxx、S3File、Healthy）；单位/业务系统显示名称。
6. **令牌唯一**：任何新样式只允许引用 §3 令牌；出现新颜色 = 违规。

## 4. 核心组件规范（正式实施时的共享组件清单）

### 4.1 StatusChip 状态灯（全局唯一状态实现）

`● 文本（·附加值）`：8px 圆点（语义色）+ 13px 文本 + 可选等宽附加值；背景 12% 同色，圆角 2px，高 22px。必须带 Tooltip 写判定时间/原因（沿用 双模入湖文档 §3.2 "Tag 旁有 Tooltip"）。禁止纯彩字、禁止同屏第三种状态样式。

### 4.2 DenseTable 密表（签名组件，产品记忆点）

- 表头：`--st-bg-panel` 加深一档 `#032A37`，13px/500，字间距 0.2px，底部 `--st-line-strong`；**不再用饱和青色实心带**。
- 行：仅行分隔发丝线；hover `--st-bg-hover`；选中行左侧 2px accent 内嵌线；**删除斑马纹**（替代现有 nth-child 纹 + 棕色 hover）。
- 列型：`名称列`（主文本 + 12px muted 副行）、`状态列`（StatusChip）、`指标列`（右对齐等宽 + 单位 muted）、`代码列`（等宽，tooltip 全文）、`时间列`（`MM-DD HH:mm`，悬浮给全年）、`操作列`（≤2 可见 + ⋯）。
- 动作分层：行内 = 1 主动作（accent）+ 1 次动作 +「更多」；删除/注销只出现在「更多」，红字 + 影响确认弹层（沿用 双模入湖文档原则 4）。
- 状态四态按 前端页面设计文档 §3.3：Loading=Skeleton 行 ×3、Empty=说明+唯一主操作、Error=Alert+重试、Partial=可显示部分+UNKNOWN。
- 密度：`density="compact|default"`，页头提供切换（记忆）。

### 4.3 FilterToolbar 筛选工具条（替代三种杂形态）

单行：`[搜索 240px] [下拉…] [分类 Segmented(含计数)] ——右侧→ [视图切换] [主按钮]`。
无 label 冒号前缀，语义写进 placeholder；二级筛选收进「筛选」Popover（替代"展开"竖排按钮）；排序只存在于列头。提交即时生效，无"搜索/重置"按钮对。

### 4.4 PageShell 全局壳（修 G3/G10）

- 侧栏默认展开 208px：分组小节名（caption 灰）+ 图标 + 文字 + 计数徽标；收起态 56px 带Tooltip。修复父级激活态错位方块 bug。
- 顶栏 48px：产品名 + 环境徽标（测试/生产，色点）＋ 当前页面标题（随路由）＋ 全局健康摘要（`运行中 n · 失败 n`，点击进任务概览）＋ 主题切换 ＋ 用户。
- 水印默认关，仅审计模式开启；"暂无数据"类深层路由必须有页壳 + 返回。

### 4.5 Workbench 三栏工作台（探查域，延续现状骨架）

比例 `240 / 1fr / 304`，面板间用 `--st-line` 分隔无外框；区域眉题仅此处保留（caption 灰 + 字距）；底部状态条保留。资源列表由"边框卡"改为**行式列表**（去 card-in-card），行内：图标 + 名称 + 类型·连接串（mono, muted）+ 归属 + StatusChip。

### 4.6 BatchBar 批量栏

浮动底部条，仅在选中 >0 时出现：`已选 n ｜ 主动作 ≤3 ｜ 更多▾ ｜ 取消`。空列表不渲染。

### 4.7 图表主题（echarts-theme-st.json，注册一次全局生效）

色阶 `['#3FC6FF','#3DD68C','#F5B83D','#7FB8D4','#2E8FB8']`；坐标轴文字 muted、轴线/分隔线 `--st-line`；柱状无渐变无描边；数值标签等宽。KPI 卡图标一律 accent 单色，禁止紫/黄装饰。

### 4.8 文案规范

中文名贯穿 菜单=页头=面包屑；动作按钮 = 动词+宾语（"创建数据源"）；toast 与按钮同词（"已创建数据源"）；连接器副标题用协议说明（"JDBC 通用连接"）不是内部代码；失败文案 = 什么坏了 + 下一步（"连不上 192.168.x.x:5236，检查网络与账号后重试"）。

## 5. 页面改造方向（对照参考原型）

### 5.1 数据源管理（prototype-datasource.html）

```
┌──────────────────────────────────────────────────────────────────┐
│ 顶栏：数据源管理            环境●测试   运行中7·失败1   ◐  用户   │
├──────────┬───────────────────────────────────────────────────────┤
│ 侧栏     │ [🔍 搜索名称/连接串] [单位▾][业务系统▾][生命周期▾]      │
│ 数据引接 │ [全部10·关系型4·OLAP2·队列1·文件2·API1]   [≡|▦] [+创建]│
│ ▂数据源  │ ┌───────────────────────────────────────────────────┐ │
│  探查    │ │  数据源          归属       连通      生命周期 探查 │ │
│  ...     │ │ ● mysql-core    装备一部/指控  ● 正常 3m  ● 启用 … │ │
│          │ │   jdbc:mysql://…（mono muted）         已探查  ⋯  │ │
```

- 列表为默认视图（密度优先），卡片退为可选；新增 类型图标列、归属列、检测时间、更新时间。
- 标签降噪：类型→图标+分类列；连通/生命周期/探查→三个 StatusChip（异常项才上色醒目，正常态弱化）——**让失败跳出来**而不是满屏绿。
- 动作：行内 `检测` + `探查` + ⋯（编辑/启停/注销/删除在菜单内）。
- 新建弹层与页面同一主题（修 G1 实例）；连接器副标题写协议说明。

### 5.2 数据探查（prototype-exploration.html）

延续三栏工作台，做四件事：资源卡改行式列表；Inspector 表详情给出**列画像**（名称/类型/空值率 mini-bar/分布）；中栏支持 表目录 → 表详情（结构/样本/画像 tab，行内mono数字）；0 值空环改为"暂无数据 + 发起探查"引导。密度：紧凑表 36px。

### 5.3 数据引接（prototype-ingestion.html）

- 健康列提前 + StatusChip（失败红点+失败原因 tooltip+行内「查看日志」）。
- 链路列：`源图标 源库.表 → 目标库.表`（mono、单行截断、tooltip 全路径），同步方式小标并入名称副行。
- 执行概况改为行内右对齐指标组：`耗时 2.4s ｜ 行数 22 ｜ QPS 0`（等宽），去掉每行 label 冒号。
- 筛选条按 4.3 重建；批量栏选中才出现；列头「执: 操作」等异常列头修复。

## 6. 与现状的兼容策略（工程路径）

1. **令牌桥接**：`design-system.less` 的 `--st-*` 名称全部保留，值按 §3 升级——存量页面引用不换名即可逐步变色。
2. **antd 正规化**：`app.tsx` 的 runtime layout 配置改用 `ConfigProvider theme={{ algorithm: theme.darkAlgorithm, token: {...}, components: {...} }}`（Context7 已核对官方定制路径），按组件 token 替代 `!important` 覆盖；每替换一个组件族，用截图对照回归。
3. **Tailwind 清理**：删除"类名映射层"（549-676 行）与内联样式劫持（966 行起），存量页面按域迁移到令牌类；迁移完一个域删一段映射。
4. **浅色主题冻结**：修复完成前隐藏主题切换（避免 G1 碎片态）；浅色 v2 待令牌层完成后用 `theme.defaultAlgorithm` 重做。
5. **ECharts**：注册 `echarts-theme-st`，存量图表逐页切换 theme 属性。
6. **i18n 噪声**：menuData 中文名补 `menu.*` 词条或关闭菜单 intl，消除控制台刷屏。

## 7. Redesign 实施计划（优先级 / 里程碑）

| 阶段 | 内容 | 范围 | 验收 |
| --- | --- | --- | --- |
| **P0 地基**（先行，1 个里程碑） | 令牌 v2 落 `design-system.less`；antd algorithm 正规化；StatusChip / DenseTable / FilterToolbar 三个共享组件；全局壳（侧栏展开态+顶栏信息+激活块 bug 修复）；浅色切换冻结 | 不动业务页面逻辑 | 现有页面在新令牌下无回归截图差异 >5%；控制台 intl 刷屏清零 |
| **P1 高频域** | 数据源管理、三个引接任务列表、任务概览（echarts 主题 + KPI 卡）按 §5 重做；新建数据源弹层同主题；术语统一（Client→引接引擎等） | 用户日常画面 | 每页密度（默认行数/屏）提升 ≥30%；动作层级 ≤2+更多；异常状态可从行内直达日志/原因 |
| **P2 深层与状态** | 探查工作台细化（Inspector 列画像）；任务详情页壳+返回；空/错/部分态按规范补齐；水印；主数据列宽修复 | 深层路由兜底 | 深链无"裸暂无数据"；四态齐全 |
| **P3 收尾** | 入湖/运维域页面套新组件；浅色 v2（令牌算法重做，可选）；引接态势占位页转正 | 全站覆盖 | 全站只存在 §3 一套令牌；`rg -c '!important' design-system.less` 较基线下降 ≥80% |

**风险**：antd 覆盖移除可能暴露隐藏样式依赖 → 以"每组件族小步替换 + Playwright 截图对照"缓解；多域并改冲突 → 按域分支串行。
